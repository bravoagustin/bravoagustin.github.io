# Portfolio · Gabriel Agustín Bravo

Portfolio personal: HTML, CSS y JavaScript sin dependencias ni build.

- `index.html`: contenido. El texto en inglés está en los atributos `data-en`.
- `styles.css`: temas claro y oscuro, diseño responsive.
- `app.js`: idioma, tema, pestañas y animaciones.
- `assets/`: CV en PDF (la página no lo enlaza).

Para probarlo en local: `python3 -m http.server 8000`.
